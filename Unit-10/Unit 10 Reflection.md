# Unit 10 Reflection

[In this unit, I learned more about improving a website for a wider audience. I focused on navigation,
consistency, and clear design principles. The challenge was making the website simple enough for users to
move around without getting confused. I overcame this by adding a clear navigation bar and using repeated
colors and styles across the page. I also thought more carefully about visual hierarchy, so important information
was easier to find. This unit connects to web development because community websites need to be clear,
accessible, and helpful for many different users.]
