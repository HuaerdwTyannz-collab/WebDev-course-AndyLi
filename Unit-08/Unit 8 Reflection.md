# Unit 8 Reflection

[Reflect on your journey here]
In this unit, I learned how responsive design helps a website work on different screen sizes. A
layout that looks good on a computer may not work well on a phone, so I used a media query to change the
navigation and pet card layout. The hardest part was understanding why the same page could look different on
different devices. I overcame this by resizing the browser and checking the design at different widths. This unit
connects to web development because modern websites need to be usable on laptops, tablets, and phones.
