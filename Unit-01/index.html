pH & pOH 高难度计算 — 全攻略

核心公式体系（必背）
pH 系
pH = −log[H₃O⁺]
[H₃O⁺] = 10⁻ᵖᴴ
pOH 系
pOH = −log[OH⁻]
[OH⁻] = 10⁻ᵖᴼᴴ
pH + pOH = 14.00  (at 25°C)
[H₃O⁺][OH⁻] = Kw = 1.0 × 10⁻¹⁴
⚠️ 有效数字陷阱：pH 的小数位数 = 浓度的有效数字位数。
例：[H₃O⁺] = 3.5×10⁻³ M（2位有效数字）→ pH = 2.46（保留2位小数）

规律：pH 每差 1 单位，[H₃O⁺] 相差 10 倍。
"pH 从 3 变到 5" → [H₃O⁺] 变小 100 倍，[OH⁻] 变大 100 倍。
强酸 pH（100% 电离）
六大强酸（必背）
HCl · HBr · HI · HNO₃ · HClO₄ · H₂SO₄（第一步）
例：0.025 M HBr 的 pH 和 [OH⁻]
1
HBr → H⁺ + Br⁻   100% 电离
[H₃O⁺] = 0.025 M
2
pH = −log(0.025) = −log(2.5×10⁻²) = 2 − log 2.5 = 2 − 0.40 = 1.60
3
pOH = 14 − 1.60 = 12.40  →  [OH⁻] = 10⁻¹²·⁴⁰ = 4.0×10⁻¹³ M
⚠️ H₂SO₄ 高难题：第一步完全电离（Ka₂ = 0.012 也算弱），BC12 一般只考第一步。
强碱 pH
强碱
LiOH, NaOH, KOH, Ca(OH)₂, Sr(OH)₂, Ba(OH)₂
⚠️ Ca(OH)₂, Sr(OH)₂, Ba(OH)₂ 每 1 mol 给出 2 mol OH⁻！
例：0.025 M NaOH
1
[OH⁻] = 0.025 M → pOH = 1.60 → pH = 14 − 1.60 = 12.40
例：0.010 M Sr(OH)₂
1
Sr(OH)₂ → Sr²⁺ + 2OH⁻  →  [OH⁻] = 2 × 0.010 = 0.020 M
2
pOH = −log(0.020) = 1.70  →  pH = 12.30
逆向高难度：已知 pH = 12.00，求 Sr(OH)₂ 浓度
1
pOH = 14 − 12.00 = 2.00  →  [OH⁻] = 10⁻² = 0.010 M
2
[Sr(OH)₂] = [OH⁻] / 2 = 0.010 / 2 = 0.0050 M
弱酸 ICE 表法（高难度核心）
弱酸只部分电离，必须 ICE 表。Ka = [H₃O⁺][A⁻] / [HA]
例 A（可近似）：0.100 M CH₃COOH, Ka = 1.8×10⁻⁵
CH₃COOH⇌H₃O⁺+CH₃COO⁻
I0.100≈00
C−x+x+x
E0.100−xxx
1
近似判断：[HA]₀/Ka = 0.100/1.8×10⁻⁵ = 5556 > 1000 ✓ 可近似
令 0.100 − x ≈ 0.100
2
1.8×10⁻⁵ = x²/0.100  →  x² = 1.8×10⁻⁶
x = 1.34×10⁻³ M = [H₃O⁺]
3
验证：1.34×10⁻³/0.100 = 1.34% < 5% ✓
4
pH = −log(1.34×10⁻³) = 2.87
例 B（不能近似，用二次方程）：0.0100 M HF, Ka = 3.5×10⁻⁴
[HA]/Ka = 0.0100/3.5×10⁻⁴ = 28.6 < 1000 → 必须用二次方程
x² + Ka·x − Ka·[HA]₀ = 0
x = ( −Ka + √(Ka² + 4·Ka·[HA]₀) ) / 2
1
x = (−3.5×10⁻⁴ + √((3.5×10⁻⁴)² + 4×3.5×10⁻⁴×0.0100)) / 2
= (−3.5×10⁻⁴ + √(1.225×10⁻⁷ + 1.4×10⁻⁵)) / 2
= (−3.5×10⁻⁴ + √1.413×10⁻⁵) / 2
= (−3.5×10⁻⁴ + 3.759×10⁻³) / 2
= 1.70×10⁻³ M
2
pH = −log(1.70×10⁻³) = 2.77
⚠️ 若强行近似 x≈√(Ka×C) = 1.87×10⁻³，误差 10%，超标！
从 pH 反推 Ka（高频考题）
1
pH 已知 → [H₃O⁺] = 10⁻ᵖᴴ = x
2
[A⁻] = x（与 [H₃O⁺] 相等）
[HA]eq = [HA]₀ − x  （x 已知，不能近似分母！）
3
Ka = x² / ([HA]₀ − x)
弱碱 ICE 表法
Kb = [BH⁺][OH⁻] / [B]
例：0.10 M NH₃，Kb = 1.8×10⁻⁵ → pH?
NH₃⇌NH₄⁺+OH⁻
I0.100≈0
C−x+x+x
E0.10−xxx
1
0.10/1.8×10⁻⁵ = 5556 > 1000 → 近似 ✓
x = √(Kb×C) = √(1.8×10⁻⁵×0.10) = 1.34×10⁻³ M = [OH⁻]
2
pOH = −log(1.34×10⁻³) = 2.87
pH = 14 − 2.87 = 11.13
从 pH 反推 Kb（WR#8 类型题，高难度）
核心逻辑：pH 已知 → x 精确已知 → 代入求 Kb，分母不能近似。
1
pOH = 14 − pH → [OH⁻] = 10⁻ᵖᴼᴴ = x
2
[B]eq = [B]₀ − x  （不能省略 x！）
3
Kb = x² / ([B]₀ − x)
完整例子：0.0200 M 甲胺，pH = 11.40，求 Kb
1
pOH = 14 − 11.40 = 2.60  →  [OH⁻] = 10⁻²·⁶⁰ = 2.51×10⁻³ M
2
[甲胺]eq = 0.0200 − 0.00251 = 0.01749 M
3
Kb = (2.51×10⁻³)² / 0.01749
= 6.30×10⁻⁶ / 0.01749 = 3.6×10⁻⁴
⚠️ pH = 11.40 小数两位 → 答案取 2 位有效数字 (3.6×10⁻⁴)

阳离子来自阴离子来自pH例子
强碱强酸= 7NaCl, KNO₃
强碱弱酸> 7NaCH₃COO

高难度：计算 1.0 M NaCH₃COO 的 pH
CH₃COO⁻ 水解：CH₃COO⁻ + H₂O ⇌ CH₃COOH + OH⁻
Kb(CH₃COO⁻) = Kw/Ka(CH₃COOH) = 10⁻¹⁴/1.8×10⁻⁵ = 5.6×10⁻¹⁰
CH₃COO⁻⇌CH₃COOH+OH⁻
I1.000
C−x+x+x
E1.0−xxx
1
5.6×10⁻¹⁰ = x²/1.0  →  x = 2.37×10⁻⁵ M = [OH⁻]
2
pOH = 4.63  →  pH = 14 − 4.63 = 9.37
最高难：双离子均水解（NH₄F 类型）
1
NH₄⁺ 水解 Ka(NH₄⁺) = Kw/Kb(NH₃) = 10⁻¹⁴/1.8×10⁻⁵ = 5.6×10⁻¹⁰（产 H₃O⁺）
2
F⁻ 水解 Kb(F⁻) = Kw/Ka(HF) = 10⁻¹⁴/3.5×10⁻⁴ = 2.9×10⁻¹¹（产 OH⁻）
3
Ka(NH₄⁺) = 5.6×10⁻¹⁰ > Kb(F⁻) = 2.9×10⁻¹¹ → 产酸 > 产碱 → 酸性 pH < 7
只需比较大小，不需计算 pH 精确值。

例 C：多元酸 — 15.00 mL 0.100 M H₃PO₄ + 0.100 M NaOH → 完全中和需多少 mL?

log 速算技巧（考场必备）
log 2 = 0.301  ·  log 3 = 0.477  ·  log 5 = 0.699
log 4 = 0.602  ·  log 6 = 0.778  ·  log 7 = 0.845
log 8 = 0.903  ·  log 9 = 0.954
  • log(a × 10⁻ⁿ) = log a − n  →  pH = n − log a
  • 例：[H⁺] = 2.5×10⁻³ → pH = 3 − log 2.5 = 3 − 0.40 = 2.60
  • 例：[H⁺] = 3.2×10⁻⁵ → pH = 5 − 0.505 = 4.50
  • [H⁺] 翻倍 → pH 减少 0.30（= log 2）
  • [H⁺] 变 10 倍 → pH 减少 1.00
