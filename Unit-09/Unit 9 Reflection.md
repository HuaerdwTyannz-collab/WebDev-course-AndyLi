# Unit 9 Reflection

[In this unit, I learned that JavaScript adds interactivity to websites. HTML creates the content, CSS
styles the content, and JavaScript makes the page respond to user actions. I used JavaScript to make a button
show a random pet care tip. The most challenging part was understanding how the button connects to the
function. I overcame this by using clear variable names and testing the button many times. This unit connects to
the web development process because JavaScript makes websites feel more active and useful instead of only
being static pages.]
